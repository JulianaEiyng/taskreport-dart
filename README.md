# TaskReport Dart

## Sobre o projeto

O TaskReport Dart é um simulador de tratamento de dados de tarefas em Dart.

O projeto simula o retorno de uma API por meio de uma lista de mapas, transforma esses dados em objetos e gera relatórios com base nos status das tarefas.

## Como executar

Certifique-se de ter o Dart instalado. Para verificar, abra o terminal e digite:

```bash
dart --version
```

Para executar o projeto, navegue até a pasta do projeto e rode:

```bash
dart run main.dart
```
